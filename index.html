How I use AI

Claude · ChatGPT · Claude Code
  1. Spec

    Write the feature as inputs, server vs. client responsibilities and edge cases before prompting.

  2. Generate

    Ask the AI for a ModuleScript skeleton or a focused function, never a whole game.

  3. Review

    Read every line: validate remotes on the server, disconnect connections, remove deprecated APIs.

  4. Test

    Play-test in Studio with a local server and several clients; reproduce bugs, then fix.

  5. Optimize

    Check the MicroProfiler and script activity; move effects to the client when needed.

AI speeds up boilerplate, UI wiring and debugging. Gameplay rules, security checks and final quality are my responsibility, and I treat AI output like a pull request from a junior teammate.
